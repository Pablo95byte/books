# Icone PWA - Bibliothèque

## Come Generare le Icone

1. **Apri il generatore di icone:**
   ```bash
   # Dal browser, apri il file nella root del progetto:
   open generate-icons.html
   ```

2. **Clicca sul pulsante "Genera Tutte le Icone"**
   - Verranno scaricate automaticamente 8 icone in formato PNG

3. **Sposta le icone in questa cartella**
   ```bash
   mv ~/Downloads/icon-*.png public/icons/
   ```

## Design dell'Icona

L'icona rappresenta un libro aperto in stile vintage francese con:
- Sfondo beige crema (#f5f1e8)
- Libro in tonalità marrone e legno
- Accenti oro antico
- Decorazioni ornamentali negli angoli
- Segnalibro bordeaux
